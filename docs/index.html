火羽直播实时字幕 · 浏览器插件

在 B站 直播间看直播时，把日语→中文实时字幕直接叠在画面上，像原生字幕一样看。

⚡ 一键安装（推荐）

点下面的按钮下载一个启动器，双击运行即可 —— 不用懂开发者模式，不用手动装，会自动下载插件并打开浏览器。

一键安装并打开「Milky_Vtuber」直播间 双击运行 → 自动装好插件并打开 Edge
安装并打开「火羽ひのめ」 只下载扩展包 (.zip)
Windows Edge / Chrome 109+ v1.1.2 无需管理员权限

📖 它怎么工作（三步）

1
下载启动器 —— 就是上面那个按钮，双击运行。
2
自动安装插件 —— 启动器会把插件解压到本机并让浏览器加载（只影响它自己打开的窗口，不动你平时的浏览器）。
3
看直播就有字幕 —— 打开支持列表里的直播间，几秒后字幕自动出现。
想调字号 / 行数 / 字幕延迟，点浏览器右上角的扩展图标。

❓ 常见问题

为什么不能像装 App 那样"点一下就装好"？
浏览器出于安全考虑，只允许从官方扩展商店静默安装，其它来源必须由用户自己确认加载。上面的启动器已经把这个步骤自动化了，是能做到的最省事的方式。

字幕和画面对不上？
这是正常的：字幕是实时的，而直播画面有 2~10 秒缓冲。点扩展图标把「字幕延迟」调到刚好跟上画面（普通清晰度先试 6~8 秒，低延迟模式试 3~5 秒）。

字幕一直不出现？
点扩展图标看状态：显示「未开播」就是主播没播；显示线路异常就点「重新探测线路」或手动切另一条线路。

会不会串台 / 看到别人的字幕？
插件按直播间隔离，只会显示当前直播间对应的字幕源。若线路被切到别的房间，插件会拒绝显示并提示。

关掉浏览器后还要重装吗？
不用重装，但要重新双击一次启动器（或按启动器里显示的路径手动打开）。想永久安装：打开 edge://extensions → 打开「开发者模式」→「加载解压缩的扩展」→ 选解压目录。

非官方工具，与哔哩哔哩及主播无关。字幕内容由第三方服务器提供，本插件只负责取回并显示。请合理使用，勿高频重连。
